# SIA008 — `[assembly: ExternalId]` cannot be applied

| Severity | Code fix | Applies with `dotnet format` |
|----------|----------|------------------------------|
| Error    | No       | No |

Fires on an `[assembly: ExternalId(typeof(T), "Member", "Id")]` attribute the analyzer could never apply: `T` (with its base types and interfaces) has no property or field named `Member`, or no non-empty id was supplied. Either way the mapping is dead — the member it was meant to tag stays untagged and every flow out of it stays unreported — so the build stops rather than pretending the member is covered.

Only attributes in the compilation being built are checked. A mapping read from a referenced assembly is not editable from here and is skipped.


## Example

```cs
using Microsoft.Graph.Models;

// SIA008: DirectoryObject has no member named "ObjectId"
[assembly: ExternalId(typeof(DirectoryObject), "ObjectId", "EntraObject")]

// SIA008: no id
[assembly: ExternalId(typeof(DirectoryObject), nameof(DirectoryObject.Id))]
```

Build output:

```
SIA008: [ExternalId] for 'DirectoryObject.ObjectId' names no property or field of that type or its bases. Fix: reference an existing member, e.g. nameof(DirectoryObject.Id).
SIA008: [ExternalId] for 'DirectoryObject.Id' has no id. Fix: supply a non-empty domain name, e.g. [assembly: ExternalId(typeof(DirectoryObject), "Id", "Customer")].
```


## How to fix

Name the member with `nameof` so the compiler checks it, and give the id the value identifies:

```cs
[assembly: ExternalId(typeof(DirectoryObject), nameof(DirectoryObject.Id), "EntraObject")]
```

`ExternalId` covers properties and fields only. A parameter or return value of a library method cannot be mapped; wrap the call in a method of the consuming project and tag that (`[return: Id("...")]`, or `[Id("...")]` on the parameter) instead.

There is no code fix because the analyzer cannot know which member or which domain was intended. See "Tagging members of referenced assemblies" in the readme for what a mapping does once it applies.
